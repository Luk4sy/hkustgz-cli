# 图书馆四楼单人预约与取消验收

2026-11-11 在 macOS、专用 Chrome 会话及同版本 CLI 和 Codex Skill `0.1.0-alpha.6` 上，以图书馆四楼 403 研修间完成一次本人单人预约及取消。版本提交为 `2af2306`，包含经复审的取消请求修复 `42ad466`。

| 步骤 | 实测结果 |
| --- | --- |
| 空闲查询 | 查到目标日开放与已占用时段，选取开放范围内未显示占用的 60 分钟 |
| 创建预览 | `ready`，本人 1 人，无费用。学校在提交时裁决额度、权限和冲突 |
| 创建 | 对有效预览取得用户确认后提交一次。退出码 0，`outcome=confirmed`，`approvalState=approved` |
| 取消预览 | 使用创建回执的来源预约 ID 精确查询。预览为 `ready`，在距离开始严格超过 10 分钟的取消窗口内 |
| 取消 | 对取消预览另行取得用户确认后提交一次。退出码 0，`outcome=confirmed`。确认依据为学校业务回执 |

首份创建预览过期后重新生成，并再次取得用户确认。上述记录仅保留脱敏验收结论。

本阶段按四楼研修间本人单人范围收尾。详情、创建预览、创建、取消预览和取消在 alpha.6 中均为 `experimental`。多人预约暂缓。实测覆盖一个账号、一个房间和上述操作窗口。M0 的 G-R1～G-R3 及其他未决项见[二期 Spec](../superpowers/specs/2026-11-01-library-booking-phase-2-spec.md)和[M0 记录](library-booking-phase-2-m0.md)。
